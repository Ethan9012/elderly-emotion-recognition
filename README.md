# 長者臉部情緒辨識

電腦視覺課程期末專題：辨識老人臉部情緒，解決因失智症導致的口語情緒表達困難。

## 動機

失智症長者常因語言能力退化，難以用言語表達疼痛或不適；心率、血壓等生理數據也很難反映情緒，照護者因此不容易理解長輩的需求。這個專題把臉部表情轉成情緒標籤，目標是在偵測到異常情緒時提醒照護者。

## 方法

1. **輸入**：相機間斷拍攝的照片，目前以 `figure2/` 資料夾中的圖片模擬。
2. **臉部特徵點**：用 MediaPipe Face Mesh 找出臉部特徵點，取嘴角（61、291）、上下唇（13、14）、左眉（65）、左眼上緣（159）。
3. **幾何特徵**：
   - `Smile`：嘴角平均高度減去嘴唇中心高度，越負代表笑得越明顯
   - `Open`：嘴巴張開高度除以嘴巴寬度
   - `Brow`：眉眼距離除以嘴巴寬度
4. **規則分類**：先判斷 Pain，再依門檻分成 Happy、Surprised、Angry、Neutral。
5. **輸出**：每張圖片的情緒標籤與三項特徵值。

## 執行

```bash
pip install -r requirements.txt
python emotion_recognition.py
```

輸出格式：

```text
<檔名>, Emotion: <情緒>, Smile=<值>, Open=<值>, Brow=<值>
```

## 注意事項

- 專題使用的測試照片來自網路圖庫，版權不屬於本專題，所以沒有放進 repo。請把要分析的臉部照片放進 `figure2/`，支援 `.jpg`、`.jpeg`、`.png`、`.bmp`。
- 分類門檻是依原本那組測試照片調整的，換成其他照片可能需要重新調整。
- 程式使用 MediaPipe 舊版 Solutions API（`mp.solutions.face_mesh`）。如果安裝的 MediaPipe 已移除這個 API，請改裝仍支援它的版本。
- 主程式原檔名為 `test4.py`。
